# 💰 LOP VPF02 — Sistema de Vendas

Programa desenvolvido em **C** para trabalhar conceitos de lógica de programação aplicados ao controle de vendas.

## 📁 Arquivos

- `vendas.c` — código-fonte
- `vendas.csv` — dados utilizados pelo programa
- `vendas.exe` — executável do projeto

## 🛠️ Tecnologia

- C

## 🎯 Objetivo

Praticar programação em C, manipulação de arquivos e processamento de dados de vendas.

## ▶️ Como executar

Para recompilar o projeto, abra `vendas.c` em uma IDE compatível com C e compile o código.

> O arquivo `.exe` foi gerado para ambiente Windows. Para outros sistemas, recomenda-se recompilar o código-fonte.
